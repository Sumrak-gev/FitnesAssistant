# 🏋️ Фитнес-помощник

**Питание, тренировки и цели — в одном мобильном приложении.**

Фитнес-помощник — проект на Flutter для расчёта калорий, белков, жиров и углеводов (КБЖУ), работы с тренировочными программами и отслеживания достижений.

**Flutter / Dart · Material 3 · Android / iOS · Версия 0.1.0**

> Сейчас это ранний прототип: навигация и базовая бизнес-логика реализованы, экраны используют демонстрационные данные. Профиль пользователя и постоянное хранение данных ещё предстоит подключить.

## Возможности

| Раздел | Что доступно сейчас |
| --- | --- |
| 🍽️ КБЖУ | Дневная норма калорий и БЖУ на примере фиксированных параметров пользователя |
| 💪 Тренировки | Список программ с демонстрационной программой «Ноги и грудь — базовый уровень» |
| 🎯 Цели | Четыре варианта: похудение, набор массы, поддержание веса и выносливость |
| 🏆 Достижения | Стартовый список из трёх достижений; автоматическое открытие пока не реализовано |

В сервисах и моделях также реализованы функции, которые пока не подключены к интерфейсу:

- расчёт нормы КБЖУ по весу, росту, возрасту, полу и цели;
- расчёт суммарного отклонения от целевой калорийности за переданный период;
- подбор замены упражнению по группе мышц с исключением указанных противопоказаний;
- фильтрация программ по противопоказаниям и замена упражнения в модели программы.

## Быстрый старт

### 1. Подготовьте окружение

- Установите Flutter SDK отдельно от репозитория и добавьте его в `PATH`. Ограничение Dart в проекте: `>=3.0.0 <4.0.0`; Dart входит в Flutter SDK.
- Для Android установите Android SDK и подготовьте эмулятор или подключите устройство с включённой отладкой по USB.
- Для iOS нужен macOS с Xcode и настроенным окружением для сборки Flutter-приложений.

Проверьте окружение и доступные устройства:

```sh
flutter doctor
flutter devices
```

Устраните замечания `flutter doctor`, относящиеся к выбранной платформе. На Windows можно разрабатывать и запускать Android-версию.

### 2. Установите зависимости

Откройте терминал в корне проекта — в папке с `pubspec.yaml`:

```sh
flutter pub get
```

### 3. Запустите приложение

Запустите эмулятор или подключите телефон, затем выполните:

```sh
flutter run
```

Если доступно несколько устройств, выберите нужное по идентификатору из `flutter devices`:

```sh
flutter run -d <device-id>
```

После запуска откроется раздел **КБЖУ**. Нижняя панель позволяет переключаться между питанием, тренировками, целями и достижениями.

## Структура проекта

```text
lib/
├── main.dart                 # Точка входа, тема и навигация
├── models/                   # Продукт, упражнение, программа, цель, достижение
├── data/                     # Репозитории продуктов и тренировок
├── services/                 # Расчёт КБЖУ, подбор упражнений, список достижений
├── screens/
│   ├── nutrition/            # Экран КБЖУ
│   ├── workouts/             # Экран тренировочных программ
│   ├── goals/                # Экран целей
│   └── achievements/         # Экран достижений
└── widgets/                  # Общие компоненты интерфейса
assets/                       # Ресурсы приложения; пока только .gitkeep
test/                         # Виджет-тест запуска и наличия четырёх вкладок
android/                      # Конфигурация Android
ios/                          # Конфигурация iOS
```

Экраны используют сервисы и репозитории, а модели описывают данные приложения. Репозитории сейчас возвращают встроенные наборы продуктов и упражнений из памяти.
