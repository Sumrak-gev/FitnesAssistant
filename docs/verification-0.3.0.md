# Проверка pre-alpha 0.3.0

Дата: 21 октября 2026. Проверка относится к рабочей ветке
`Drevniy_Jomolungmik`.

## Выполнено локально

- `flutter analyze` на Flutter 3.47.7: ошибок нет.
- `flutter test` с локальным тестовым API: 81 тест прошёл.
- `pytest` в `server/` с отдельной тестовой PostgreSQL: 50 тестов прошли.
- `docker compose --env-file server/.env.example --profile production config --quiet`: конфигурация корректна.
- `flutter build apk --debug` с локальным Android SDK/JDK 21: APK 0.3.0+3 собран.
- Виджеты КБЖУ, тренировок, прогресса и настроек проверены снимками экрана 390×844.
  На экране прогресса показаны этапы 1–5 и 6–10; бело-синяя палитра выбирается
  в настройках, рядом с ней показан флаг Израиля. Карточка с изображением
  и внешней Telegram-ссылкой проверена в заблокированном состоянии до уровня 6
  и в открытом состоянии с уровня 6.

## Что ещё требует проверки перед публичным выпуском

- CI после публикации коммита на Flutter 3.47.5. Локальный Flutter 3.47.7,
  поэтому совпадение результата на закреплённой версии подтверждает CI.
- Уведомления, фоновый WorkManager, процесс регистрации и синхронизации на
  физическом Android-устройстве, в том числе после потери сети и перезапуска.
- Настоящий HTTPS-домен, цепочка Caddy → nginx → Uvicorn и отдельные IP-бакеты
  rate limit для разных клиентов на реальном сервере.
- Собственный keystore, релизная сборка и проверка установки релизного APK/AAB.

Статус — pre-alpha. Локальный debug APK не является подписанным релизом.
