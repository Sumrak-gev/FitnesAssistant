# Авторизация

Вход по email, пароль 10–128 символов, имя только для отображения.
`SecureTokenStore` хранит один JSON с парой access/refresh, device UUID и server user UUID
в `flutter_secure_storage`; токенов нет в Drift. Android backup/transfer данных отключён.
Device UUID стабилен для пары установка/email и не присваивается другому пользователю на сервере.

Первый вход привязывает локального владельца к серверному аккаунту через AppSettings.accountId.
UUID локальных продуктов/порций сохраняются; user_id запроса сервер берёт из JWT.
Выход закрывает локальные разделы экраном входа. Для сохранности и изоляции одна установка
поддерживает один аккаунт; попытка войти другим не переносит и не отправляет его данные.
Выход записывает устойчивую отметку локальной сессии в secure storage: запоздавший ответ
фонового refresh не может восстановить вход, даже после завершения процесса приложения.
При офлайн-выходе токены удаляются на устройстве; серверные сессии этого device отзываются
при следующем входе, а access ограничен 15 минутами.
